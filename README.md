# Personal Office Expense Invoice Generator 🧾

A modern, fast, and fully responsive web application designed for offices and businesses to generate, track, and download petty cash receipts, employee expense vouchers, and cash distribution slips instantly. 

Created with ❤️ by **Tanveer Hussain ([@vexornull](https://Instagram.com/vexornull))**.

---

## 🌟 Key Features

- **Itemized Expense Breakdown:** Add multiple items with quantities and unit prices; totals calculate automatically in real-time.
- **Save as JPG:** Export clean, high-resolution `.jpg` receipt images instantly using client-side canvas rendering (`html2canvas`).
- **Direct WhatsApp Sharing:** Share receipt summaries directly through WhatsApp with formatted text messages.
- **Local History Management:** Automatically saves generated invoices in your browser's `localStorage` so you can review or reload past expenses.
- **Fully SEO-Optimized:** Structured with semantic HTML5, Open Graph tags, and rich meta keywords for maximum search engine visibility.
- **Dark & Light Mode:** Toggle seamlessly between dark and light themes for comfortable viewing in any lighting environment.
- **Print Friendly:** Built-in print styles for direct printing on standard office printers.

---

## 🛠️ Tech Stack

- **HTML5 & CSS3** (Semantic layout and styling)
- **Tailwind CSS CDN** (Modern utility-first styling)
- **FontAwesome** (Professional icons)
- **html2canvas** (DOM-to-image JPG export utility)
- **Vanilla JavaScript (ES6+)** (Dynamic state management and local storage)

---

## 🚀 Quick Start / Installation

Because this tool is built as a **Single-File Application**, you don't need complex Node.js build steps, databases, or server configurations to run it!

1. Download or clone the repository containing `index.html`.
2. Open the `index.html` file in any modern web browser (Google Chrome, Microsoft Edge, Firefox, Safari).
3. Start generating and downloading your office expense receipts!
